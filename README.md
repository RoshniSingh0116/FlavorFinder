# 🍽️ **FlavorFinder (Tastify)**

**FlavorFinder (Tastify)** is a modern **recipe discovery web application** that allows users to **search, filter, and explore meals** using the **TheMealDB API**.

---

## 📌 **Project Overview**

**FlavorFinder** helps users discover **delicious recipes from around the world**.  
Users can **search for meals**, **filter by categories**, and view **detailed cooking instructions** in an interactive UI.

### 🚀 **This project demonstrates:**
- **API Integration**
- **DOM Manipulation**
- **Responsive UI Design**
- **Dark / Light Mode**
- **LocalStorage Usage**

## 🔗 **Public API Used**

This project uses the **TheMealDB API** to fetch recipe data.

### 📍 **Base URL**
https://www.themealdb.com/api/json/v1/1/

### ⚡ **Endpoints Used**

- **Search Meals by Name**  
  https://www.themealdb.com/api/json/v1/1/search.php?s=chicken  

- **Get Random Meal**  
  https://www.themealdb.com/api/json/v1/1/random.php  

- **Lookup Meal by ID**  
  https://www.themealdb.com/api/json/v1/1/lookup.php?i=52772  

### 📌 **Description**

- `search.php?s=` → Returns meals based on search query  
- `random.php` → Returns a random meal  
- `lookup.php?i=` → Returns full details of a specific meal by ID

## ▶️ **How to Use**

1. **Enter a recipe name** in the search bar  
2. Click **Search**  
3. Use **category buttons** to filter meals  
4. Click **Random** for a surprise recipe  
5. Click **View** to see instructions  
6. Click ❤️ to **save favorites**  
7. Toggle 🌙 for **dark mode**
